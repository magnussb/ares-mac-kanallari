# Ares — maç kanalları

Ares Media Player'ın **Maç Programı** ekranı için hangi maçın Türkiye'de hangi kanalda
yayınlandığını gösteren veri.

- **Fikstür:** ESPN (açık veri, anahtarsız)
- **Kanal bilgisi:** beIN SPORTS (kendi sitesi), TV+ ve D-Smart yayın akışları ([iptv-org/epg](https://github.com/iptv-org/epg) aracıyla)
- **Güncelleme:** GitHub Actions her saat çalışır, `mac_kanallari.json` dosyasını yeniler.

Uygulama yalnızca gerçekten eşleşen maçlarda kanal yazar; tahmin yapılmaz.
